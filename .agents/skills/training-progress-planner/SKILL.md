# トレーニング進捗確認・次回目標提案スキル

## 概要
指定された部位（肩/背中/脚）について、環境変数 `$WEIGHT_TRAINING_LOG` フォルダの日別JSON（`YYYY-MM-DD.json`）から過去30日間のトレーニング進捗を確認し、次回のトレーニング目標をダブルプログレッションに基づいて提案する。

- 本スキルは読み取り専用であり、記録ファイルには書き込まない。記録の作成は `weight-training-log` スキルの責務。
- 部位判定（種目名 → 筋群）は `exercise-classifier` スキルを用いる。

## ワークフロー

1. 部位を確認する（肩 / 背中 / 脚 のいずれか）。不明な場合は質問する。
2. 過去30日間の記録を集める。
   - `$WEIGHT_TRAINING_LOG` 配下の `YYYY-MM-DD.json` を列挙し、今日を含む過去30日分のファイルを読み込む。
   - 対象の日付範囲（例: `2026-09-06 〜 2026-10-05`）をユーザーに明示する。
   - 対象期間内に該当部位の記録がない場合は、その旨を伝え、より古い記録を参照するか、新規種目で始めるかをユーザーに確認する（推測しない）。
3. 対象期間の全ファイルから種目名を重複排除し、`skill` ツールで `exercise-classifier` スキルを読み込み、その分類ルールに従って各種目名を1件ずつ筋群に分類する。
   - 分類結果に指定部位が含まれる種目だけを進捗対象にする。
   - 複数筋群（例: `背中、脚`）は指定部位に含めるが、「複数筋群の種目であること」を出力に併記する。
   - `未判定` の種目は集計から除外し、ユーザーに「対象に含めるか」を確認する。
4. 種目ごとに日付順で進捗を集計する。
   - 実施回数（セッション数）と初回・最終日付
   - 重量の推移（表記ゆれは「表記の正規化」に準じて扱う）
   - セット×回数の推移、総ボリューム（重量 × レップ総和）
5. 「ダブルプログレッション判定」に従って次回の目標を算出し、「出力形式」に沿って提示する。

## ダブルプログレッション判定

基準：**直近セッションの全セットが10レップに達したら、次回セッションで重量を上げる**。

| 直近セッションの状態 | 次の目標 |
| --- | --- |
| 全セットが10回以上 | 重量を上げ、レップ目標は10回に戻す |
| 全セットが10回未満 | 重量を維持し、10回目標で回数UP |
| 自重種目（`自重`/`bodyweight`）で全セット10回以上 | 加重版への移行を提案（例: `pull up` → 加重懸垂、`bulgarian squat` → 負荷ブルガリアンスクワット）。加重種目に移行後は重量の増減ルールに従う |

重量の増加幅：

- ダンベル系: 1片につき +1kg（例: `8kg` → `9kg`）
- バーベル・マシン系: 通常2.5kg。実際の装置の最小刻みが不明な場合は、2.5kg / 1.25kg のいずれかをユーザーに確認する。

時間系種目（`duration` を持つもの、例: `farmers walk`）：

- 各セッションで目標時間を **+10秒** 上げる（例: `70 secs` → `80 secs`）。
- 全セットの目標時間が **5分（既定値。ユーザーの指示で変更可）** に達したら、重量を上げる（`12.5kg` → `13.5kg`）し、時間目標をリセットする。

## 表記の正規化

| 表記 | 扱い |
| --- | --- |
| `自重`, `bodyweight` | 自重。重量は増加させず、回数のみでプログレッション |
| `12.5kg per hand` | ダンベルの片手持ち重量。1片あたりに +1kg で増加 |
| `70 secs`, `1min`, `90 seconds` | 秒に換算して比較（`1min` = 60秒） |
| `8kg` 等の重量 | セット・レップデータと組み合わせて総ボリュームを算出 |

## 出力形式

進捗と目標を次のMarkdown形式で提示する。

```markdown
## 進捗確認（{部位} / 過去30日: {開始日}〜{終了日}）

### {種目名}（{n}セッション）
| 日付 | 重量 | セット×レップ | 総ボリューム |
| --- | --- | --- | --- |
| 2026-09-28 | 8kg | 3×10 | 240kg |
| 2026-10-01 | 9kg | 3×10 | 270kg |

- 総ボリューム = 重量 × レップ総和（1セッション分）。
- 自重種目は重量を `自重` と表記し、総ボリューム欄は `-` とする。
- 複数筋群の種目（例: 背中＋脚）にはその旨を併記する。

## 次回目標（ダブルプログレッション）
| 種目 | 次回の重量 | 目標セット×レップ | 根拠 |
| --- | --- | --- | --- |
| dumbbell shoulder press | 10kg | 3×10 | 直近セッションで 3×10 達成 |
| pull up | 自重 | 3×10 | 直近 3×5 → 回数UP |
```

## 注意点

- 記録ファイルには一切書き込まない。
- 種目名が英語・日本語で混在しても問題なく、分類は `exercise-classifier` スキルのルールで行う。
- 判断が明確でない場合（不明な増分量、未判定種目の扱いなど）は、推測で回答せずユーザーに質問する。
